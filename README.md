# ทีมโทรอัพเซลล์ (ตัวอย่าง)

เว็บสำหรับทีมโทรอัพเซลล์ รับรายชื่อจาก Pancake (ออเดอร์ POS + แชท) แจกให้พนักงาน และบันทึกผลการโทร

> เวอร์ชันนี้เป็น **ตัวอย่างหน้าเว็บ** ใช้ข้อมูลสมมติ เก็บไว้ในเบราว์เซอร์เครื่องที่เปิดเท่านั้น ยังไม่ได้เชื่อม Pancake จริง

## ฟีเจอร์ในตัวอย่าง
- **คิวโทรของฉัน**: เรียงลำดับให้อัตโนมัติ (นัดโทรกลับที่ถึงเวลา → ยังไม่โทร → ไม่รับสาย) กดโทรออกได้จากมือถือ เปลี่ยนสถานะด้วยปุ่มหรือกดเลข 1–6
- **สถานะ**: ไม่รับสาย, นัดโทรกลับ (เลือกวันเวลา), ได้คุยยังไม่ซื้อ, ขายได้ (ใส่ยอด), ไม่สนใจ, เบอร์ผิด
- **สรุปผล**: รายชื่อรวม, ได้คุย, ขายได้, %ปิดการขาย, %ปิดจากชื่อ, ยอดขายเพิ่ม แยกช่องทางและรายคน
- **รายชื่อทั้งหมด**: ค้นหา กรอง ย้ายผู้รับผิดชอบ ดาวน์โหลด CSV
- **ตั้งค่า**: วิธีแจกรายชื่อ, เพิ่ม/ลบพนักงาน
- ปุ่ม **ดึงรายชื่อใหม่จาก Pancake** จำลองการรับรายชื่อ พร้อมข้ามเบอร์ซ้ำภายใน 30 วัน

## วิธีขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `upsell-call-center`)
2. อัปโหลดไฟล์ `index.html` และ `README.md` (กด **Add file → Upload files**)
3. ไปที่ **Settings → Pages**
4. ที่ **Source** เลือก `Deploy from a branch` แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` กด **Save**
5. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/upsell-call-center/`

> ถ้าใช้ GitHub แบบฟรี repository ต้องเป็น Public ถึงจะเปิด Pages ได้ ข้อมูลตัวอย่างไม่มีปัญหา แต่ห้ามใส่ API key หรือข้อมูลลูกค้าจริงลงในไฟล์

## ขั้นต่อไป (เวอร์ชันจริง)
GitHub Pages เป็นเว็บแบบ static เก็บความลับไม่ได้ จึงจะใช้ Google Apps Script เป็นหลังบ้าน:

```
Pancake POS (webhook ออเดอร์) ─┐
Pancake แชท (API ดึงทุก 5 นาที) ─┼─> Google Apps Script ──> Google Sheet (ฐานข้อมูล)
                                 │         ▲
                                 │         │ fetch()
                                 └── เว็บบน GitHub Pages (ไฟล์นี้)
```

- API key ของ Pancake เก็บใน Script Properties ของ Apps Script
- หน้าเว็บเรียก Apps Script แทน localStorage เพื่อให้ทั้งทีมเห็นข้อมูลชุดเดียวกัน
- เพิ่มระบบล็อกอินพนักงาน (เช่น Google Sign-In หรือรหัส PIN)
